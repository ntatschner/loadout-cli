# SpendBars

SpendBars draws `loadout usage --by <grouping>`.

- **By project, model or agent**: one row per group, largest first: its name, a bar against the largest, and its figure. A folder that is not a registered project is hatched and says "not a project". Only the twenty largest show; "The 7 smallest are left out here."
- **By day**: columns, oldest on the left. Hover a day, or focus the chart and use the arrow keys (Home and End for the ends); the readout above says the day and its figure, and is live for screen readers. The axis names every few days.
