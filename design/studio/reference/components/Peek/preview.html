Each body: as it opens on hover or focus, and pinned

Unpinned, it is a glance: it closes when the pointer or focus leaves. Pinned (the row's peek button, or pressing anything inside it), it is a dialog that stays, with Close, and Tab moves into it.

Live: hover a row, focus it, or press its peek button

Hover opens it after 350ms beside the row, kept on screen; focus opens it at once. The peek button pins it. Escape closes it first. A click away closes one that is not pinned. Below 600px wide it is a sheet from the foot.

Mode bar

    The waiting list: the mode bar's count

    Every waiting item, oldest first, each with its main action. A run or an idea opens its own peek in the same panel, with the way back. Pressing the count again, or Escape, closes it.

    Minimal: a short block under the row

    In Minimal the peek is an expansion in the column, before the frame opens: four lines, the state and the actions. It opens on focus or with the peek button, never on hover, so nothing moves under the pointer.
