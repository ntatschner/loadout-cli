# TokenSplit

TokenSplit is the top of the Spend page: the period's spend in one number, **billed as input** (`billedInputEquivalent` from `loadout usage`), and what the cache saved.

- Under it, one bar split four ways: input (solid accent), read from the cache (hatched), output (grey) and thinking (dotted). The patterns and the list below carry the split, so colour never does alone.
- The list gives each figure; "Read from the cache" also says how much of input it was.
- "Since …" names the start, and says in Needs when some transcripts could not be read, so the figures are a floor.
- Figures read 11.3M, 38.5M, 1.2k. No budget words: Spend shows what was spent, and thresholds belong to team runs.
