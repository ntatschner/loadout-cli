# SessionTabs

SessionTabs is Terminal Focus's strip of sessions: one tab each, with its state as a Signal glyph (the word is its accessible text), its title, project and agent, its key (Ctrl+Alt+1 to 9), and a dot when it has written since you last looked at it.

- A session that needs you gets a Needs underline as well as its glyph.
- Arrow keys move between tabs and show the session. Double-click a tab to show only that one.
- The + opens the launch sheet.
- The strip scrolls sideways inside itself when there are more tabs than room; the page never does.
