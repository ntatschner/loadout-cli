# RefusalsList

RefusalsList is "What it was refused and decided" on a run's page, folded from the run's journal (`RunLeftBehind.Decisions`, today used only for delivered refs):

- tools a node's permissions refused or allowed (`node.answered`, `permission.asked`);
- nodes the lead asked for and could not have (`request.refused`);
- gates answered, refused or merged (`gate.decided`, `gate.refused`);
- reports returned to the lead, with the reasons (`report.checked` returned).

Each row: the time, a glyph and the outcome as a word (refused in Bad, allowed and merged in Good), what, and the detail. A **Refused (n)** filter narrows it. It is a read: nothing here acts.
