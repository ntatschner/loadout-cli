# ValueReport

ValueReport is the **What it did** tab of Spend, beside **What it cost**. It says what Loadout did for you over the same period, **counted, never estimated**: no "hours saved", no money saved beyond what the cache already reports on What it cost.

- **The head**: one sentence of the largest true figures.
- **Groups** (Sessions, Memory, Safety, Team runs), each a grid of figures: the count, what it counts, and the command or file it comes from.
- **A figure Loadout does not record yet** is drawn hollow: "not counted yet", what it will count, and "counted once the event log ships". It never shows a zero it cannot vouch for.
- **How this is counted**: on this machine, from what Loadout records; nothing leaves it.

What exists today and what waits on the new event log is listed in `ROUND4.md`.
