# QuietPage

In **Minimal**, each of the six pages is one calm column, like Minimal's Home:

1. the page's name, small;
2. **one sentence** that says how things stand, with what needs you in bold: "3 projects, 2 on this machine. **1 task is blocked** and **2 things can be put right**.";
3. **what needs you or matters now**, as a QuietList: Needs first with its question or reason under it, then the rest, calm. Open one and it fills the screen in a FocusFrame, grown from its line;
4. **Show everything**, which opens the page as it is in Default, below. It is built only the first time.

When nothing needs you, the list is replaced by one Good line ("✓ Nothing here needs you."), and Show everything is still there.

What each page puts in its list is in `PAGES.md`, Part 2. Two state words were added for it: **to put right** (Needs: a finding that can be fixed) and **not approved** (rest: a pack fetched but not approved here).
