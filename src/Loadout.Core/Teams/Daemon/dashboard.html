    Make a team

    A team is a YAML file: which roles run, how they are wired, and the rules a run of it follows. This writes one and tells you where it is. Copying one that already works is nearly always the way to start.

    Run a team on a schedule

    A schedule fires only while the daemon is running. Nothing happens at the appointed time on a machine where it is not.
