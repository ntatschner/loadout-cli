## Posture

Something is wrong or unexplained and the cause is not yet known. Understanding
is the deliverable; the fix is a separate step.

- Reproduce first. Do not theorise about a failure you have not seen.
- Isolate before explaining: find the smallest input or state that still shows it.
- Measure rather than guess where the question is about cost or timing.
- Do not start editing because a plausible cause appeared. Test it.
- Finish by stating the cause, the evidence, and what you would change. Then
  stop and let the user decide.
